# AlphaChatT-
AlphaChat, créée par Vivien Wendpayangda SINA, est une application de messagerie sécurisée permettant de discuter gratuitement avec ou sans Internet. En ligne, elle passe par le Cloud ; hors ligne, elle utilise le Bluetooth et le Wi-Fi Direct pour échanger des messages chiffrés directement de téléphone à téléphone via un réseau maillé (Mesh).
